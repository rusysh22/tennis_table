📖 Panduan Integrasi Lisensi & Siklus Berlangganan

1️⃣ Sistem Heartbeat (Pemeriksaan Berkala)

Setelah diaktifkan, server ini akan melakukan pemeriksaan otomatis (heartbeat / validate) secara berkala ke Berlanggan.web.id. Token lisensi diperbarui otomatis sehingga Anda tidak perlu menginput kunci lagi.

2️⃣ Masa Tenggang (Grace Period)

Jika saldo wallet Anda di Berlanggan.web.id kurang saat tanggal jatuh tempo bulanan/tahunan, lisensi tidak langsung diputus! Sistem masuk masa Grace Period (3 hari) agar website Anda tetap berjalan murni tanpa gangguan selagi Anda melakukan top-up.

3️⃣ Pemeliharaan Seat Perangkat (Installations)

Setiap aktivasi mendaftarkan 1 seat berbekal Fingerprint di atas. Jika Anda memindahkan server turnamen ini ke mesin atau domain lain, cukup klik tombol Lepas Lisensi (Deactivate) agar seat kosong dan siap digunakan di server baru Anda!
